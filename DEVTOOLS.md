# B4. Refelction


The website makes many requests because it needs to load different things like pictures, designs, and other files before the page looks complete. While doing this activity, I noticed that loading a website can take longer when the internet connection is slow. The Slow 4G result made me realize that not everyone has a fast and stable internet connection. Here in Davao Oriental, some people experience weak signals, especially in areas far from the city. That's why I think websites should be simple and load faster so people can still use them even with a slow internet connection.
